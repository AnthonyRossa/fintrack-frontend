# FinTrack

A React-based personal finance tracker designed to help users manage income, expenses, and financial reports. This frontend application provides a responsive, intuitive interface for tracking financial data with real-time updates and secure authentication.

## 🚀 Features

*   **Secure Authentication**: JWT-based login and registration with protected routes.
*   **Expense Management**: Add, view, and delete expense entries.
*   **Income/Entry Tracking**: Manage income entries and financial inflows.
*   **Financial Reporting**: Visualize data through detailed reports.
*   **Exchange Rates**: Track and manage currency exchange rates.
*   **Responsive Design**: Optimized layout for desktop and mobile devices.
*   **Real-time Updates**: Instant UI updates upon adding or deleting items.
*   **User Context**: Centralized state management for user sessions and data.
